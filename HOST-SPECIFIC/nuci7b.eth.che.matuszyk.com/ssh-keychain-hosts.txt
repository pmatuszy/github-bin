# ssh-keychain-hosts.txt
#
# Host list for ssh-keychain-daemon.sh (details: ssh-keychain-daemon.sh --help).
#
# One host or user@host per line. Blank lines and anything after # are ignored.
# Re-read at the start of every cycle, so edits take effect without restarting
# the daemon in its screen window.
#
# On each host the daemon runs, over ssh:
#   /root/bin/ssh-keychain.sh --no_startup_delay batch
# with ConnectTimeout=20s, so hosts that are down are logged and skipped.
#
# Deployed by git-bin.sh: HOST-SPECIFIC/$(hostname)/* is copied into /root/bin/,
# so edit this file in the repo — the /root/bin copy is overwritten on each deploy.
#
# Do not list nuci7b itself: its keys are loaded locally when the daemon starts.
